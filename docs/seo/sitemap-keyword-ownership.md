## Rules to grow without cannibalization

1. One primary keyword (and variants) = one URL. Check this register before creating content.
2. Separate intent: commercial (Home, Apartments, Rentals) vs. informational (Guide, Kite Beach, North Coast, Blog).
3. The home summarizes and links; its H2s don't use keywords owned by other pages. Link anchors do.
4. Hub = head term; children = long-tail; two children never share a keyword.
5. No location landings where there's no inventory. If a topic already has an owner, expand that page.
6. Technical: self-referencing canonical, hreflang en/es, FAQPage schema only on /faq/, blog tags noindex, no indexable parameters.
7. Monthly Search Console check: queries with impressions on 2+ site URLs → merge (301) or rewrite one.

8. Direct booking is the main call to action on every commercial page (Book direct, 10% less than Airbnb). Airbnb links are secondary and open in a new tab.

## Growth slots (no URL changes)

- New unit → /apartments/name/. With 3+ units of the same type → a type page (e.g. /apartments/studios/) that takes the generic term from the hub.
- Properties in another area → /rentals/area/.
- Kite lessons or schools → /kite-beach-cabarete/topic/.
- New nearby destination → /north-coast/destination/.
- Informational topic with no owner → /blog/.
